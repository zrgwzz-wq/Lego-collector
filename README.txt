LEGO Collector v18
- 앱 실행 시 자동 업데이트
- 소장 세트의 Brickset 이름/연도/테마/부품수/이미지/해외가격 자동 재확인
- kr_catalog.json의 한글명/한국 정가 자동 재적용
- 마지막 자동 업데이트 상태를 화면 상단에 표시
- 업데이트 실패 시 기존 저장정보를 그대로 사용
- 최대 100개 보유 세트를 한 번에 동기화
- v17 이하 localStorage 자동 이전

중요:
현재 한국 카탈로그의 '소비'는 완전 자동입니다. 즉 kr_catalog.json이 서버에서 갱신되면
사용자는 아무 버튼도 누를 필요가 없습니다.
LEGO Korea 전체 1,000+ 상품을 자동으로 '생성'하는 수집 파이프라인은 별도 단계입니다.

GitHub: index.html, server.py, kr_catalog.json 3개 파일 반영
